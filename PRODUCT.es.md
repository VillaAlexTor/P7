# Producto

<!-- impeccable:product-schema 1 -->

## Plataforma

web

## Stack

Next.js con TypeScript para la aplicación, Go para la API de análisis y Docker Compose para orquestación local. El MVP debe funcionar sin una API de IA pagada; un modelo externo será una mejora opcional.

## Usuarios

El usuario principal es un estudiante o usuario cotidiano de internet en América Latina que necesita comprender una política antes de aceptarla. El producto también debe ser comprensible sin formación jurídica, técnica o de privacidad.

## Propósito

p7 convierte políticas y términos complejos en evaluaciones personalizadas respaldadas por evidencia. Una sesión exitosa explica qué datos declara recopilar el servicio, dónde podrían ir, qué información falta o es ambigua, qué consecuencias son posibles y qué puede hacer la persona.

## Posicionamiento

p7 combina siete mecanismos en lugar de actuar como resumidor: mapa de datos, riesgo por perfil, detección de vacíos, evidencia verificable, simulación de impacto, acciones de consentimiento y acceso bilingüe con enfoque latinoamericano. La IA puede interpretar, pero reglas deterministas verifican citas y calculan el índice.

## Contexto de uso

El usuario pega una política, selecciona un perfil y recibe un espacio de análisis. La demostración funciona localmente sin cuentas, base de datos ni API pagada. La entrega pública necesita código, instalación, divulgación de IA, demo funcional y video de hasta seis minutos.

## Capacidades y restricciones

- Texto pegado en español o inglés.
- Cláusulas estables y SHA-256 del documento normalizado.
- Detección de categorías, propósitos, terceros, conservación, derechos, seguridad y entrenamiento de IA.
- Vacíos ausentes o ambiguos sin presentarlos como prueba de ilegalidad.
- Evidencia exacta verificada antes de mostrarse.
- Índice reproducible ponderado por perfil; un LLM no fija la puntuación.
- Separación entre evidencia, interpretación y escenario.
- Mapa visual y plan priorizado.
- El documento se trata como entrada no confiable.
- Sin afirmaciones de asesoramiento legal.

## Evidencia disponible

La conversación de origen define diferenciadores, arquitectura, alcance y requisitos. No existen testimonios verificados, benchmarks, certificación jurídica, marca registrada ni despliegue de producción; no deben fabricarse.

## Principios

- Evidencia antes que interpretación.
- Índices reproducibles antes que juicios opacos.
- Consecuencias explicadas en lenguaje cotidiano.
- Incertidumbre y omisiones expresadas con honestidad.
- Privacidad accesible para comunidades latinoamericanas.

## Accesibilidad e inclusión

La aplicación es bilingüe español/inglés, cumple fundamentos WCAG 2.2 AA, permite teclado y movimiento reducido, usa lenguaje claro y no depende solo del color.
