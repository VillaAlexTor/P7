# Reflexión personal de aprendizaje

> Empecé p7 con la idea de ayudar a las personas a comprender y enter  políticas de privacidad antes de aceptarlas. Al construirlo aprendí que una respuesta convincente de cualquier IA no basta: debo mostrar la cláusula detrás de cada hallazgo y explicar qué significa el índice. La primera evaluación local descubrió un error importante: el modelo interpretó doce negaciones como si las prácticas ocurrieran. Tras revisar el prompt reconoció los casos negativos, pero todavía omitió una cláusula de conservación. Eso cambió mi forma de ver las pruebas. Una demo funcional muestra que las piezas se conectan; un conjunto etiquetado revela dónde fallan. También aprendí a mantener alineadas las experiencias en español e inglés y a distinguir el flujo declarado de datos de la conducta observada. Si volviera a comenzar, prepararía ejemplos de evaluación independientes y probaría antes la comprensión con usuarios para tener una mejor desicion.
