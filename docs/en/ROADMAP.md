# Roadmap

## Implemented MVP

- [x] Pasted-text analysis in Spanish and English.
- [x] Stable clause segmentation and SHA-256 document identity.
- [x] Evidence verification against exact source clauses.
- [x] Deterministic, profile-weighted risk index.
- [x] Missing and ambiguous disclosure detection.
- [x] Declared data-flow map.
- [x] Clearly labeled impact scenarios.
- [x] Interactive consent action plan.
- [x] Five privacy profiles and full bilingual UI.
- [x] Prompt-injection pattern isolation and safety report.
- [x] Backend, API-contract, frontend, build, and documentation-parity tests.
- [x] Docker and continuous integration configuration.
- [x] Local Ollama semantic classifier with structured output.
- [x] Forty synthetic, labeled evaluation clauses and reproducible metrics.

## Before submission

## After the hackathon
