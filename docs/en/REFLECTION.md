# Personal Learning Reflection

> I began p7 with more experience in backend development and cybersecurity than in explainable AI or product design. At first I was happy simply to see the model return structured findings. Then the first evaluation exposed a bad mistake: it read all twelve denial clauses as if those practices actually happened. The output looked confident, and it was wrong. Fixing that changed the project and also changed how I evaluate AI. I added negative controls, exact evidence checks, deterministic scoring, and later tested the frozen classifier on new official excerpts. A strong excerpt result looked encouraging, but the first complete-policy check fell to 54.5% precision and 60.0% recall. I learned not to hide an imperfect result behind a polished demo—and that an exact quote can still be interpreted incorrectly. I also underestimated the work required to keep Spanish and English truly aligned, and I resisted adding URL and PDF ingestion before the core flow was trustworthy. If I began again, I would test complete documents and user comprehension much earlier. The most useful lesson was simple: evidence matters more than confidence.
