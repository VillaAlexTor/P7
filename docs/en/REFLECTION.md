# Personal Learning Reflection

> I started p7 wanting to help people understand privacy policies before accepting them. Building it taught me that a convincing answer from any AI is not enough: I need to show the clause behind every finding and explain what the score means. The first local evaluation exposed a serious mistake: the model treated twelve denials as if those practices happened. After revising the prompt, it recognized the negative cases, but still missed one retention clause. That changed how I think about testing. A working demo shows that the pieces connect; a labeled set reveals where they fail. I also learned to keep the Spanish and English experiences aligned and to distinguish declared data flows from observed behavior. If I started again, I would prepare independent evaluation examples and test user comprehension earlier to make better decisions.
