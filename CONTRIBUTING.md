# Contributing

1. Create a small, focused branch.
2. Add tests when changing rules, profiles, translations, or JSON contracts.
3. Do not add legal claims without a verifiable source and appropriate review.
4. Keep evidence, interpretation, and hypothetical scenarios separate.
5. Update both English and Spanish documentation copies.
6. Run `./scripts/test-all.ps1` before opening a change.

Security reports must not include real privacy policies or personal data. Use synthetic, redacted examples.
